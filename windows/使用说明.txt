Bundle Desk · Windows 10 / 11 x64 便携版

完整解压 ZIP 后，双击 Start-BundleDesk.cmd。
界面会在默认浏览器中打开；使用期间保留黑色启动窗口，退出时关闭窗口即可。
不要在压缩包预览中直接运行，也不要只复制启动文件。

内置 Python、Java、ADB、aapt、bundletool、apksigner 与相关 DLL，
无需安装 Android Studio 或配置环境变量。文件仅在本机处理。

AAB：直接解析；转换时签名文件可选，未上传则自动生成并复用本机测试签名。
APK / APKS：可直接导入并安装，保留有效签名。
未签名 APK：安装前自动使用本机默认测试签名。

真机需要开启 USB 调试，在手机上允许授权；部分品牌需要额外安装官方 USB 驱动。
模拟器需要自行安装并启动，本工具不包含模拟器及 Android 系统镜像。

数据与默认测试签名位于：%LOCALAPPDATA%\Bundle Desk。
不同电脑默认测试签名不同。跨电脑更新同一应用，请上传同一份签名库。

这是浏览器界面的便携版，不是原生 Windows 窗口，也不需要安装。
当前未在 Windows 实机验证启动、转换和设备安装；构建校验和 Mac 回归测试不能代替实机验证。

可选：双击 Create-Desktop-Shortcut.cmd 创建带图标的桌面快捷方式。
创建后请保留解压文件夹的位置，否则快捷方式将失效。
